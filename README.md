# Monte-Calro-Trading-Simulator

## گام های شبیه ساز 
1 - ابتدا میزان سرمایه اولیه را مشخص کنید، اگر سرمایه اولیه شما به دلار است باید تیک تبدیل ارز را روشن کنید و قیمت طلا یا رمز ارز را وارد کنید.
2 - پس از تنظیم بقیه پارامترها، می توانید شبیه سازی را آغاز کنید.

## مشاهده و تست برنامه (Index.html)
برای اجرای نسخه ماژولار شده برنامه می‌توانید یکی از روش‌های زیر را استفاده کنید:

1. **دانلود و باز کردن محلی**: کل مخزن را به‌صورت ZIP دانلود کنید یا با `git clone` دریافت کنید. سپس فایل `index.html` را مستقیماً در مرورگر (Chrome/Firefox/Edge) باز کنید. به دلیل استفاده از ماژول‌های ES6، بهتر است از طریق یک سرور محلی ساده مثل `python -m http.server` یا `npx serve` در پوشهٔ ریشه پروژه اجرا کنید تا همه درخواست‌ها به درستی بارگذاری شوند.
2. **Github Pages (اختیاری)**: اگر مخزن را روی Github Pages منتشر کنید، کافی است شاخهٔ اصلی را فعال و صفحهٔ `index.html` را در همان مسیر ریشه قرار دهید؛ پس از آن می‌توانید از طریق آدرس Pages فایل را مستقیماً تست کنید.
3. **Codespaces/VS Code Web**: در صورت استفاده از Codespaces یا VS Code Web، یک سرور محلی (مانند `python -m http.server`) در پوشهٔ پروژه اجرا کنید و از طریق پورت منتشر شده، صفحه را در مرورگر باز کنید.

> نکته: برای اجرای صحیح، هیچ پیش‌نیازی به نصب پکیج‌های Node یا ابزار ساخت نیست؛ مرورگرهای مدرن با ماژول‌های ES سازگاری دارند.
